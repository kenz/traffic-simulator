# 🚗 渋滞シミュレータ (Traffic Merge Simulator)

> **2車線から1車線への車線規制時における「早期合流」と「ファスナー（ジッパー）合流」の交通流比較シミュレータ**

ブラウザ上で動作するインタラクティブな交通シミュレータです。  
外部ライブラリへの依存なし（Vanilla HTML5 / JavaScript / Canvas 2D / CSS）で構築されており、誰でもブラウザを開くだけでリアルタイムに挙動の違いを観察・比較できます。

🌐 **オンラインデモ**: [https://kenz.github.io/traffic-simulator/](https://kenz.github.io/traffic-simulator/)

---

## 📸 シミュレーション概要

高速道路や一般道工事などで「2車線 ➔ 1車線 ➔ 再度2車線復帰」となる道路において、**合流ルールの違いが交通流や渋滞長に与える影響**を左右並列でリアルタイムに比較検証します。

公平を期すため、左右の道路には**全く同じタイミング・同じ車線・同じ速度特性・同じ車体色の車両が完全に同期して投入**されます。

```
 [⬆️ 上部: 0m〜100m]
   ・2車線区間（公平な同期ランダムスポーン）
   
 [⚠️ 中部合流: 100m〜500m]
   ・左側: 100m地点から「すぐに合流」（空間がない場合は徐行／500m手前で停車待機）
   ・右側: 450m〜500mの先頭まで2車線キープして「交互ファスナー合流」
   
 [🚧 規制区間: 500m〜700m]
   ・1車線のボトルネック区間
   
 [↗️ 下部復帰: 700m〜1,000m]
   ・2車線規制解除（前走車に追いついた車だけが1回だけ車線変更して直進）
```

## 🚦 車両の挙動モデルとルール

### 1. 車両の基本物理
- **速度のばらつき**:
  - 車両ごとに基準速度（60 km/h）に対して **±20% の希望巡航速度** をランダムに保持。
- **前車接近時の90%減速ルール**:
  - 前の車に近づくと、**「前車の速度の90%」** まで減速（ブレーキランプ点灯）。
  - 前車と離れると、再び自身の希望巡航速度まで加速。
  - この減速連鎖により、実世界で発生する「サグ部・合流部の自然渋滞（ファントムジャム）」を再現。

### 2. 左右の合流戦略の違い

| 項目 | 🔴 【左側】すぐに合流 (Early Merge) | 🟢 【右側】ファスナー合流 (Zipper Merge) |
| :--- | :--- | :--- |
| **合流開始** | **100m地点から** すぐに合流を試みる | **450m〜500m（先頭）** まで2車線をキープ |
| **空間がある場合** | 横方向に安全な余白があれば即座に左車線へ合流 | 450m〜500mの先頭でスムーズに合流 |
| **空間がない場合** | 速度を落として徐行しながら前進。**1車線手前（500m）まで合流できなければ完全に停車して待機** | 左右の車線から**1台ずつ交互（Left ➔ Right ➔ Left）**に確実に譲り合って合流 |
| **交通への影響** | 割り込みブレーキ連鎖と先頭での停止待機により、**左車線だけが上流まで伸びる長大な渋滞**が発生 | 2車線をフル活用して渋滞長を**約半分に圧縮**し、先頭での交互合流によりボトルネックが整流化 |

### 3. ボトルネック通過後の挙動（追いつき車線変更）
- 500m〜700mの1車線区間を抜けて2車線に戻った後（700m〜1000m）：
  - **同一車線の前走車に追いついて減速した車だけが**、隣の車線の空きスペースを確認して1回だけ車線変更（追い越し）を行います。
  - **一度車線変更した車はフラグを保持し、元の車線に戻ることなくゴールまでその車線を維持**して直進します。
  - 前が空いている車はそのままの車線でスムーズに加速します。

## ⚙️ 主な機能と操作

- **リアルタイムサマリー比較カード**:
  - 通過台数（スループット）、単位時間あたりの流量、平均通過所要時間、最大渋滞長、平均走行速度をリアルタイム表示。
- **時系列グラフ**:
  - 「累積通過台数」「区間平均速度」「渋滞長」のリアルタイム折れ線グラフ。
- **再生速度コントロール**:
  - `1x` / `2x` / `5x` / `10x`（初期値は10倍速で快適に観察可能）。
- **パラメータ調整スライダー**:
  - 交通流入量（800〜2,800 台/時、初期値 2,000 台/時）
  - 車両ごとの速度ブレ幅（0%〜±40%、初期値 ±20%）
  - 前車接近時の減速係数（70%〜98%、初期値 90%）
  - 希望車間時間（0.8秒〜4.0秒、初期値 3.0秒）
- **車両ホバーツールチップ**:
  - 車両にマウスを合わせると、車両ID、現在速度、希望速度、加速度、位置、車線、合流待機状態などをポップアップ表示。

## 💻 ローカルでの実行方法

本プロジェクトはビルドツールや外部ライブラリを必要としません。

```bash
# リポジトリのクローン
git clone https://github.com/kenz/traffic-simulator.git
cd traffic-simulator

# Pythonの簡易サーバーで起動
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くだけで動作します。
